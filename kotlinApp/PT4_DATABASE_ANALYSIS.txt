# Analyse Comparative: SpinTracker vs PokerTracker 4 (2024)

## Vue d'Ensemble

| Aspect | SpinTracker | PokerTracker 4 |
|--------|-----------|---------------|
| Moteur | SQLite | PostgreSQL 12 |
| Tables principales | 20+ (avec migrations) | 38 |
| Orienté | Spin & Go | Cash + Tournois |

---

## Tables SpinTracker (Implémentées)

### Tables Principales
1. **players** - 6 colonnes
2. **tournaments** - 17+ colonnes
3. **hands** - 25+ colonnes
4. **player_hands** - 15+ colonnes
5. **stats** - 8 colonnes
6. **config** - 2 colonnes

### Tables de Lookup (Migration 2, 10)
7. **lookup_actions** - actions poker (R, F, C, X, B...)
8. **lookup_positions** - positions (SB, BB, EP, MP, CO, BTN)
9. **lookup_hand_ranks** - ranks (High Card -> Royal Flush)
10. **lookup_sites** - rooms (WIN, PS, BET, UNI, PMU)
11. **lookup_hole_cards** - 132 combinaisons (AA->22, suited/offsuit)

### Système de Tags (Migration 5)
12. **tags** - tags colorés (Nit, TAG, LAG, Fish, Whale, Reg)
13. **player_tags** - association player-tag
14. **notes** - notes sur joueurs

### Performance (Migration 6, 7)
15. **hand_histories** - historiques bruts séparés
16. **player_stats_cache** - cache stats pour HUD

---

## Tables PT4 (Réelles)

### Tables Principales
1. **player** - 8 colonnes (id_site, player_name_search, flg_anonymous)
2. **tourney_summary** - 31 colonnes (buy-in, fee, prize_pool, rebuys, addons, bounties)
3. **tourney_results** - résultats par joueur (id_player, val_finish, amt_won, cnt_rebuy, cnt_addon)
4. **tourney_hand_summary** - résumé main (pot, actors, aggressors, cards)
5. **tourney_hand_player_statistics** - **200+ colonnes** (stats détaillées par street)
6. **tourney_hand_histories** - historique brut

### Lookup Tables
- lookup_actions, lookup_hand_ranks, lookup_positions, lookup_sites
- lookup_hand_groups, lookup_hole_cards, lookup_suits_omaha, lookup_tags, lookup_tourney_type

### Système de Tags
- **tags** - tags colorés
- **notes** - notes manuelles
- **notes_auto** - notes automatiques

### Tables Additionnelles
- tourney_cache, tourney_custom_cache, tourney_blinds
- tourney_table, tourney_table_type
- cash_* (8 tables cash game)
- live_* (4 tables live poker)

## Différences Clés et Suggestions

### 1. Normalisation (Lookup Tables)

**PT4**: Tables de lookup avec IDs référencés everywhere
**SpinTracker**: ✅ Déjà implémenté (Migration 2, 10)
- lookup_actions, lookup_positions, lookup_hand_ranks, lookup_sites, lookup_hole_cards

**Suggestion**: OK - Keep current implementation

---

### 2. Multi-Room / Multi-Site

**PT4**: `id_site` sur **TOUTES** les tables avec FK référencée
**SpinTracker**: ✅ Déjà implémenté (Migration 3)
- site_id ajouté à players, hands, tournaments

**Suggestion**: OK - Ajouter FK sur lookup_sites si pas encore fait

---

### 3. Stats Détaillées par Street (Preflop/Flop/Turn/River)

**PT4**: 200+ colonnes avec flags détaillés:
- flg_p_vpip, flg_p_first_raise, flg_p_3bet, flg_p_3bet_opp, flg_p_3bet_def_opp
- flg_f_cbet, flg_f_donk, flg_f_float, flg_f_check_raise
- flg_t_cbet, flg_t_donk, flg_t_float, flg_t_check_raise
- flg_r_cbet, flg_r_donk, flg_r_check_raise
- +100+ colonnes pour amounts

**SpinTracker**: ✅ Migration 4, 10
- flg_vpip, flg_pfr, flg_3bet... (preflop)
- flg_cbet_flop, flg_donk_flop... (flop/turn/river)
- Migration 10: flg_*_opp (opponent flags)

**Suggestion**: Ajouter:
```sql
-- Plus de flags post-flop
ALTER TABLE player_hands ADD COLUMN flg_raise_flop INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN flg_raise_turn INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN flg_raise_river INTEGER DEFAULT 0;
-- Check-call, check-fold
ALTER TABLE player_hands ADD COLUMN flg_xc_flop INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN flg_xf_flop INTEGER DEFAULT 0;
```

---

### 4. Amounts par Street

**PT4**: Amounts détaillés par position
- amt_bet_p, amt_bet_f, amt_bet_t, amt_bet_r
- amt_p_raise_facing, amt_p_2bet_facing, amt_p_3bet_facing
- amt_f_raise_facing, amt_f_2bet_facing, amt_f_3bet_facing
- amt_t_raise_facing, amt_t_2bet_facing
- amt_r_raise_facing, amt_r_2bet_facing

**SpinTracker**: Limité dans Migration 10
- amt_before, amt_raise_facing, amt_2bet_facing, amt_3bet_facing

**Suggestion**: Ajouter par street
```sql
ALTER TABLE player_hands ADD COLUMN amt_bet_f INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN amt_bet_t INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN amt_bet_r INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN amt_raise_f_facing INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN amt_raise_t_facing INTEGER DEFAULT 0;
ALTER TABLE player_hands ADD COLUMN amt_raise_r_facing INTEGER DEFAULT 0;
```

---

**PT4**: amt_p_effective_stack, amt_f_effective_stack, amt_t_effective_stack, amt_r_effective_stack

## TOUS LES GAPS À COMBLER

### Gap 1: Amounts par Street
PT4: amt_bet_f, amt_bet_t, amt_bet_r, amt_raise_f_facing, amt_raise_t_facing, amt_raise_r_facing
SpinTracker: Limité - amt_before, amt_raise_facing (global seulement)
→ AJOUTER: amt_bet_f, amt_bet_t, amt_bet_r, amt_raise_f_facing, amt_raise_t_facing, amt_raise_r_facing

### Gap 2: Players par Street (cnt_players_f/t/r)
PT4: cnt_players_f, cnt_players_t, cnt_players_r (nombre de joueurs restants)
SpinTracker: player_count (global seulement)
→ AJOUTER: players_flop, players_turn, players_river dans hands

### Gap 3: Aggressor Positions par Street
PT4: str_aggressors_p/f/t/r, val_f_raise_aggressor_pos, val_t_raise_aggressor_pos
SpinTracker: aggressor_position (global seulement)
→ AJOUTER: aggressor_position_flop, aggressor_position_turn, aggressor_position_river

### Gap 4: SPR Turn/River
PT4: Calculé via effective_stack / pot à la volée
SpinTracker: spr_flop seulement
→ AJOUTER: spr_turn, spr_river dans player_hands

### Gap 5: Import Tracking
PT4: date_imported dans tourney_hand_summary
SpinTracker: Pas de tracking
→ AJOUTER: imported_at dans hands

### Gap 6: Blind Structures
PT4: tourney_blinds (structure complète des niveaux de blinds)
SpinTracker: Pas implémenté
→ AJOUTER: table blind_structures si analyse par niveau requise

### Gap 7: Tourney Types
PT4: tourney_table_type (Speed, Hyper, KO, Progressive KO)

### Gap 8: Player Name Search

### Gap 10: Combo Types (Hand Combinations)

### Gap 14: Action Counts (cnt_f_raise, cnt_t_raise)
PT4: cnt_f_raise, cnt_f_call (nombre d'actions par street)

### Gap 15: Pots详情 (amt_pot_p/f/t/r)

### Gap 20: Rebuy Period End
PT4: date_rebuy_period_over
SpinTracker: Pas implémenté

### Gap 21: Tourney Summary Complète
