================================================================================
1. CHAMPS MISSING / INCOMPLETS
================================================================================

--------------------
MANQUANTS:
--------------------

- limit_type          # NL (No Limit), PL (Pot Limit), FL (Fixed Limit), SL (Spread Limit)
- game                # HOLDEM, OMAHA, OMAHA8, RAZZ, STUD, etc.
- currency            # USD, EUR, GBP, etc.
- button_seat         # Numéro du siège du bouton (dealer)
- ante                # Montant des antes (pour tournois)
- tournament_id       # ID du tournoi
- tournament_name     # Nom du tournoi
- tournament_level    # Niveau actuel du tournoi
- buyin_currency      # Devise du buy-in
-rake_per_player      # Rake payé par chaque joueur

--------------------
INCOMPLETS:
--------------------

- position            # Stocké comme string (BTN, SB...) mais devrait être INT (0-9)
- blinds              # String "0.10/0.25" mais devrait être structuré: {sb: 0.10, bb: 0.25}
- total_pot           # Float seul, devrait avoir: main_pot, side_pots[]

--------------------
NON TRAITÉS:
--------------------

- split_pot           # Pots partagés (plusieurs gagnants)
- run_it_twice        # Multiple runouts ( river )
- side_pots           # Pots secondaires quand all-in

--------------------
EXEMPLE 2: BET -> CALL -> RAISE -> RERAISE
--------------------

Texte original:
"""
*** FLOP *** [Js 7d 2c]
Hero: bets 10
Villain: calls 10
Button: raises to 30
Hero: raises to 70
Button: calls 70
*** TURN *** [Js 7d 2c] [4h]
"""

Structured actions:
```json
{
  "actions": [
    {"street": "flop", "order": 1, "player": "Hero",       "type": "deal_board",  "cards": ["Js", "7d", "2c"]},
    {"street": "flop", "order": 2, "player": "Hero",       "type": "bet",        "amount": 10,   "effective": 10, "is_all_in": false},
    {"street": "flop", "order": 3, "player": "Villain",    "type": "call",       "amount": 10,   "effective": 10, "is_all_in": false},
    {"street": "flop", "order": 4, "player": "Button",     "type": "raise",      "amount": 30,   "effective": 20, "is_all_in": false},
    {"street": "flop", "order": 5, "player": "Hero",       "type": "raise",      "amount": 70,   "effective": 40, "is_all_in": false},
    {"street": "flop", "order": 6, "player": "Button",      "type": "call",       "amount": 70,   "effective": 40, "is_all_in": false},
    {"street": "turn", "order": 1, "player": "Button",      "type": "deal_board", "cards": ["4h"]}
  ]
}
```

Requête pour trouver ce pattern:
```sql
-- PostgreSQL avec JSON
SELECT * FROM hands 
WHERE actions @> '[{"type":"bet"},{"type":"call"},{"type":"raise"},{"type":"raise"}]'
  AND jsonb_array_length(actions) >= 4;
```

================================================================================
3. RECOMMANDATION STOCKAGE
================================================================================

Pour les stats rapides (VPIP, PFR, etc):
- Colonnes BOOL pré-calculées à l'import

Pour les patterns complexes (bet->call->raise):
- Stocker actions en JSONB dans PostgreSQL
- Utiliser index GIN pour requêtes rapides

Volume < 500k mains: JSONB suffit
Volume > 500k mains: Table HandActions séparée recommandée


================================================================================
4. SCHÉMA JSONB SUGGÉRÉ POUR POSTGRESQL
================================================================================

```sql
-- Ajout colonne actions JSONB
ALTER TABLE hands ADD COLUMN actions JSONB;

-- Index pour requêtes patterns
CREATE INDEX idx_hands_actions_gin ON hands USING gin(actions);

-- Exemples de requêtes:

-- Trouver toutes les mains ou hero a bet sur le flop
SELECT * FROM hands WHERE actions @> '[{"street": "flop", "type": "bet"}]';

-- Trouver bet -> call -> raise -> reraise
SELECT * FROM hands WHERE actions @> '[{"type":"bet"},{"type":"call"},{"type":"raise"},{"type":"raise"}]';

-- Compter les fois ou hero 3-bet preflop
SELECT COUNT(*) FROM hands 
WHERE actions @> '[{"street": "preflop", "type": "raise"}]'
  AND jsonb_path_exists(actions, '$[*] ? (@.type == "raise" && @.effective >= 20)');
```
