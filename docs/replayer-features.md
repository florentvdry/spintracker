# Replayer Features

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space | Play/Pause |
| ← | Previous step |
| → | Next step |

## Controls

### Playback Speed
Select from 0.5x, 1x, 2x, 4x

### View Mode
- **Chips**: Show stack/pot values in chips
- **BB**: Show values in big blinds

### Options
- **Folded**: Toggle visibility of folded players

## Visual Indicators

### Player States
- **Active**: Blue border glow
- **All-In**: Orange border + ALL-IN badge
- **Folded**: Grayscale + FOLD badge (can be hidden)

### Action Colors
- **Fold**: Red
- **Check**: Gray
- **Call/Bet**: Blue
- **Raise**: Green
- **All-In**: Orange
- **Blinds**: Purple

## Animations

- **Card Deal**: Cards flip when dealt to players
- **Pot Collection**: Winner chip badge animates on pot win
